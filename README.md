# calculator_the_best

Локальный веб-калькулятор на Python. Нужен установленный Python 3; дополнительные библиотеки не требуются.

## Запуск в Windows

1. Откройте PowerShell в папке проекта.
2. Выполните `python server.py` (если команда не найдена, попробуйте `py server.py`).
3. Откройте в браузере http://127.0.0.1:8000.
4. Для остановки сервера нажмите Ctrl+C в окне PowerShell.

Нажимайте кнопки мышью или используйте клавиатуру: цифры и `+`, `-`, `*`, `/`; Enter или `=` вычисляет результат, Backspace удаляет символ, Escape очищает экран. Кнопка `%` делит текущее число на 100. Например, `12 + 8` и Enter дают `20`.

Кнопки «Звук» и «Чудик» включают и выключают забавные звуки и бегущего помощника. После вычисления чудик радуется и говорит случайную фразу. Звук появляется после нажатия кнопки калькулятора.

Если порт 8000 уже занят, остановите программу, которая его использует, или измените номер порта в `server.py` и откройте соответствующий адрес.
